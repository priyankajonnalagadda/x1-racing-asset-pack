# X1 Racing Asset Pack

A stylized real-time racing asset project designed for mobile and prototype racing games.

## Included Assets
- Futuristic Racing Checkpoint Gate
- Render Setup
- Texture Workflow
- Export Pipeline
- Portfolio Planning

## Software Used
- Blender
- Substance Painter
- Unity

## Features
- Low-poly game-ready structure
- Real-time workflow
- Unity-compatible export setup
- Organized production folder structure

## Folder Structure
- Blender_Files → source models
- Exports → FBX/OBJ export notes
- Textures → material workflow
- Renders → preview renders
- References → design inspiration
- Portfolio → presentation planning
